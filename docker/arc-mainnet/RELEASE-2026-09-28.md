## Release blocker

The primary public RPC returns 429 during initial sync and live indexing. A 2 RPS
transport completed backfill but accumulated live lag; an 8 RPS cap again hit rate
limits. A read-only probe to the officially listed QuickNode public endpoint
returned chain ID 5042, but its third request also returned 429. No paid RPC was
purchased or API key added. A dedicated endpoint with sufficient sustained
throughput is required before reopening the public entry point. Do not interpret
`/health` or an empty contest list alone as proof of current indexing.

The HTTPS/API smoke check passed before the public entry was closed for final
acceptance. Mainnet-copy rendering subsequently passed on the server loopback;
the replacement UI still needs public browser acceptance after RPC is configured.
